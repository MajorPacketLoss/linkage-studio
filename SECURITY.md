# Security

Linkage Studio is a static client-side application. The app has no server-side accounts or mechanism storage. Saved drawings are local JSON files; they are not automatically uploaded to the repository or shared with other visitors.

## Reporting a concern

Use GitHub's private vulnerability reporting if it is available for this repository. Otherwise, open an issue requesting a private contact channel without including exploit instructions, credentials or personal files.

For ordinary bugs, use the bug report template. Include only the smallest drawing needed to demonstrate the issue and remove private project information before attaching it.
